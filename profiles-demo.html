🎚️ kuziSlicer Profiles Manager

Export, import, and manage printer & filament profiles

📋 Overview Ready

The Profiles Manager feature enables seamless exchange of printer and filament configurations across your kuziSlicer installations.

Export to YAML

  • Save all profiles locally
  • Share via GitHub/cloud
  • Backup configurations

Import from Multiple Sources

  • Local YAML files
  • GitHub repositories
  • Any HTTPS URL

Profile Types

  • Printer profiles
  • Filament profiles
  • Extensible format

Merge Modes

  • Merge (keep existing)
  • Replace (overwrite)
  • No deps required

🔌 IPC Handlers

5 new Electron IPC channels expose the profiles API to the renderer process:

profiles:export-yaml

Export all profiles to a YAML file and save locally.

await invoke('profiles:export-yaml', targetPath?)

profiles:import-file

Load profiles from a local YAML file.

await invoke('profiles:import-file', filePath)

profiles:import-github

Clone profiles from a GitHub repository.

await invoke('profiles:import-github', owner, repo, branch?, filePath?)

profiles:import-url

Fetch profiles from any HTTPS URL.

await invoke('profiles:import-url', url)

profiles:merge

Combine imported profiles with existing ones.

await invoke('profiles:merge', imported, overwrite?)

💾 ProfilesManager Service

src/main/services/profilesManager.ts — Core service implementing all profile operations.

static exportToYaml(printers, filaments): string static saveProfilesYaml(filePath, printers, filaments): void static importFromFile(filePath): {printers, filaments} static importFromGithub(owner, repo, branch?, filePath?): Promise static importFromUrl(url): Promise static mergeProfiles(existing, imported, overwrite?): {printers, filaments}

Key features:

  • ✓ Hand-coded YAML parser (no external deps)
  • ✓ HTTPS support for GitHub and URL imports
  • ✓ Merge with collision detection (by ID)
  • ✓ Extensible for new profile types

🚀 Getting Started

1. Export Your Profiles

import { profilesApi } from './utils/profilesApi' const result = await profilesApi.exportYaml() console.log('Profiles saved to:', result.path)

2. Import from GitHub

const profiles = await profilesApi.importFromGithub( 'your-username', 'profiles-repo', 'main' )

3. Merge with Existing

const merged = await profilesApi.mergeProfiles(profiles, false) // false = merge only new profiles, keep existing // true = replace all profiles
